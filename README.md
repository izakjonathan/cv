# Izak Hyllested CV Webpage

Static CV webpage for GitHub + Working Copy + Vercel.

## Files

- `index.html` — main page
- `styles.css` — full visual system and responsive layout
- `script.js` — reveal animations and footer year
- `assets/profile.jpeg` — profile image
- `assets/Izak_Hyllested_CV.pdf` — downloadable CV PDF

## Deploy on Vercel

1. Push this folder to a GitHub repository.
2. Import the repository in Vercel.
3. Use the default static site settings.
4. Deploy.

No build step is required.
